# Folder screenshots/

Taruh semua screenshot bukti instalasi di dalam folder ini dengan nama file yang persis seperti di bawah:

- `01-git-version.png`
- `02-git-config.png`
- `03-docker-version.png`
- `04-docker-hello-world.png`
- `05-vscode-extensions.png`

Contoh cara membuat screenshot di Windows:
1. Buka terminal (PowerShell) dan jalankan `git --version`, simpan hasilnya sebagai gambar.
2. Ulangi untuk perintah lain.
3. Taruh semua gambar di folder ini sebelum commit.
